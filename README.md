# AD Contábil — Next.js

Site institucional da AD Contábil (contabilidade para profissionais da saúde).

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm start
```

Deploy: Vercel · domínio `adcontabil.net.br`
